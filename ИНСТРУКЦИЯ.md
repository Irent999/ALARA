# РХБЗ VR Тренажёр: запуск из .exe, VR через SteamVR, установочный пакет

## 1. Что куда положить (от корня проекта, рядом с `package.json`)

| Файл из архива | Действие |
|---|---|
| `electron/main.cjs` | ЗАМЕНИТЬ |
| `src/App.tsx` | ЗАМЕНИТЬ |
| `src/scene/webxrManager.ts` | ЗАМЕНИТЬ |
| `src/vr/vrHudChip.ts` | новый файл (рядом с `vrUiSystem.ts`) |
| `src/props/`, `src/render/` | новые папки |
| `public/layouts/catalog.json`, `layout.json` | новые файлы |
| `package.build-block.json` | не файл проекта: его содержимое вставьте в `package.json` вместо блока `"build": { ... }` |

Если у вас уже стоят `src/props/`, `src/render/` и `public/layouts/` из прошлого архива, замените их этими.

## 2. Сборка установщика (на Windows)

```
npm install
npm run electron:build
```

В папке `release/` появятся:
- `RHBZ-VR-Setup-<версия>.exe` — установщик (ярлык на рабочем столе и в меню «Пуск», можно выбрать папку);
- `RHBZ-VR-Portable-<версия>.exe` — версия без установки (запуск из любой папки или с флешки).

Если сборка пожалуется на иконку: положите `public/icon.ico` (256×256) или удалите строку `"icon": ...` в блоке `win`.

## 3. Что нужно на другом компьютере

1. Windows 10 или 11.
2. Google Chrome или Microsoft Edge (Edge встроен в Windows 10/11).
3. Steam и **SteamVR** (бесплатно). Шлем HTC Vive подключён и настроен в SteamVR.
4. Запустить установщик, затем ярлык «РХБЗ VR Тренажер».

Никаких флажков в `chrome://flags` включать не нужно, настройки Windows не меняются.

**Первый вход в VR:** браузер один раз спросит «использовать виртуальную реальность?» — нажмите «Разрешить». Ответ запоминается.
Если SteamVR ещё не запущен, он стартует сам при нажатии «ВОЙТИ В VR» (первый раз 10–30 секунд).

**Предупреждение SmartScreen** («Windows защитил ваш компьютер»): установщик не подписан сертификатом разработчика.
Нажмите «Подробнее» → «Выполнить в любом случае». Чтобы предупреждения не было, нужен сертификат подписи кода (платный).

## 4. Как теперь решаются проблемы подключения шлема

| Раньше | Теперь |
|---|---|
| «WebXR нужен HTTPS» | Приложение открывается по адресу `http://localhost:ПОРТ`. Для браузера это безопасный адрес, HTTPS не нужен. Сервер слушает только этот компьютер. Если всё же открыть страницу по IP-адресу сети, приложение подскажет об этом отдельным сообщением. |
| Включать флажки `chrome://flags` | Не нужно. Запуск идёт с правильными параметрами. |
| Выбирать SteamVR как OpenXR-рантайм вручную | Запуск сам находит SteamVR (в том числе на другом диске) и передаёт его браузеру. Системные настройки не меняются. |
| Сессия зависает после первой ошибки | Сессия закрывается при сбое; кнопка одна и блокируется на время запуска. |

Выбор VR-рантайма автоматический: если SteamVR запущен или в системе не назначен рантайм, используется SteamVR;
если SteamVR не запущен и активен другой рантайм (например, Meta Quest Link), он не трогается.
Принудительно: добавьте к ярлыку в поле «Объект» `--xr-runtime=steamvr` или `--xr-runtime=system`.

## 5. HUD в шлеме

- Постоянная кнопка **«СВЕРНУТЬ HUD» / «ПОКАЗАТЬ HUD»** висит слева-внизу в поле зрения (на уровне пояса).
  Наведите луч контроллера и нажмите курок.
- Кнопка **Menu** на контроллере тоже переключает HUD (если шлем её передаёт браузеру).
- Исправлена ошибка: кнопка **Grip** на Vive больше не переключает HUD. Она нужна для захвата и телепорта, и раньше
  HUD сворачивался при каждом захвате.

## 6. Если что-то не работает

1. Откройте `Win+R` → `%APPDATA%` → папка приложения → **`launcher.log`**. В нём записано, какой браузер и какой
   VR-рантайм выбраны, и все ошибки запуска. Пришлите этот файл, если нужна помощь.
2. Кнопка показывает «VR НЕ ПОДДЕРЖИВАЕТСЯ»: запустите SteamVR и проверьте, что шлем виден (зелёный значок),
   затем перезапустите приложение.
3. Автоматический выбор не сработал: в SteamVR → Настройки → «Разработчик» → «Назначить SteamVR рантаймом OpenXR»,
   либо запустите с `--xr-runtime=steamvr`.
4. Приложение открылось, но VR нет: проверьте, что запущено в Chrome/Edge, а не в окне Electron
   (запуск с `--embedded` открывает именно обычное окно без VR).
5. Режим разработки: `npm run electron:dev` (или откройте `http://localhost:3000`, а не адрес по IP).
